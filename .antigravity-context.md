# CONTEXTO DEL PROYECTO: SERVIDOR MINECRAFT PAPERMC (TLAUNCHER / GCP)

## 📌 PROYECTO, TIPO Y ENTORNO
- **Proyecto:** `SERVER_TLAUNCHER` (`Server-Minecraft`)
- **Tipo de Proyecto:** Infraestructura & Despliegue de Servidor de Juegos (PaperMC en Google Cloud Compute Engine + Docker Compose + SSH).
- **Motor / Versión:** PaperMC `1.21.1` (imagen base `itzg/minecraft-server:latest`, Java 21).
- **Infraestructura:** VM Google Cloud `e2-standard-4` (4 vCPUs, 16 GB RAM), Debian 12 (Bookworm).
- **Modo de Conexión:** Offline-mode / No-Premium (`ONLINE_MODE: "FALSE"`) con soporte simultáneo para TLauncher y cuentas Mojang Premium.
- **Control de Versiones:** **Git Activo** (Repositorio remoto: `https://github.com/maurosanvargas/SERVER_TLAUNCHER.git`).

## 🛠️ COMPONENTES, ARCHIVOS Y HERRAMIENTAS
- **Archivos Clave:**
  - `docker-compose.yml`: Configuración central de PaperMC, flags JVM, puertos y lista de plugins (Modrinth + URLs directas).
  - `README.md`: Documentación completa con protocolo Git, reglas de firewall y comandos administrativos.
  - `start.sh` / `stop.sh`: Scripts bash de arranque con logs y apagado seguro con persistencia.
- **Persistencia en Disco:**
  - `./data:/data`: Almacena mundos (`world`, `world_nether`, `world_the_end`), `plugins/`, `whitelist.json` y base de datos de permisos.
- **Comandos Recurrentes (SSH en VM):**
  - Gestión: `./start.sh` | `./stop.sh` | `sudo docker compose logs -f`
  - Whitelist: `sudo docker compose exec minecraft rcon-cli whitelist add <Nick>`
  - Operador: `sudo docker compose exec minecraft rcon-cli op <Nick>`

## ⚠️ ALERTAS, CONFLICTOS Y REGLAS DE ORO
1. **PROTOCOLO GIT-FIRST OBLIGATORIO (Para el Asistente de IA):**
   - Ante cualquier cambio en archivos locales, el asistente DEBE responder PRIMERO con:
     1. Local: `git add .` -> `git commit -m "..."` -> `git push`
     2. VM: `git pull` -> `./stop.sh && ./start.sh`
   - No proponer comandos in-game ni RCON sin haber sincronizado y reiniciado el contenedor primero.
2. **Flags de Sleep-Most:**
   - Comandos `/sm setflag` solo pueden ejecutarse por un operador in-game (no por consola RCON).
3. **Aviso de Actualización de Sleep-Most:**
   - La alerta de versión de SpigotMC en los logs de arranque es puramente informativa y se puede ignorar; la versión 5.5.3 es 100% estable en 1.21.1.
